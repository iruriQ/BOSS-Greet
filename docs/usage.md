# 详细使用说明

[返回项目首页](../README.md)

## 新手安装（电脑端）

**普通使用只需：电脑浏览器 + 篡改猴 + 本助手脚本。** 不需要编程，也不用下载整个项目。

### 先准备什么

| 项目 | 是否需要 |
| --- | --- |
| 电脑与浏览器 | 使用 Windows 或 macOS 电脑，推荐较新版本的 Chrome 或 Microsoft Edge；不能直接装进 BOSS 手机 App |
| 篡改猴 | 必须安装，它是让助手在招聘网页上运行的浏览器扩展 |
| 招聘账号 | 需要在同一个浏览器登录自己的 BOSS 直聘账号 |
| AI 接口和密钥 | 固定话术、筛选及使用平台默认招呼不需要；仅 AI 定制需要自行配置，费用按服务商规则计算 |
| VPN／网络工具 | 助手不强制要求；安装、更新需能访问扩展商店和 GitHub，AI 模式还需能访问所填接口，取决于自己的网络环境 |
| 其他软件与账号 | 不需要 Node.js、Python、终端、服务器或编程软件；下载公开版不需要 GitHub 账号 |

### 按这 5 步安装并开始使用

1. **安装篡改猴。** 用 Chrome 或 Edge 打开 [Tampermonkey 官网](https://www.tampermonkey.net/)，选择自己的浏览器，进入其官方扩展商店，点击「添加至浏览器」。
2. **允许运行用户脚本。** 右键篡改猴图标 →「管理扩展程序」→ 开启「允许用户脚本」。若没有此项，按篡改猴提示，在 `chrome://extensions` 或 `edge://extensions` 开启「开发者模式」。详见 [篡改猴官方说明](https://www.tampermonkey.net/faq.php?locale=zh&q=Q209)。
3. **安装助手。** 点击 [安装 BOSS Greet 通用版](https://raw.githubusercontent.com/iruriQ/BOSS-Greet/main/boss-auto-apply.user.js)，在篡改猴安装页点击「安装」。若只显示代码：篡改猴图标 →「管理面板」→「实用工具」→「从 URL 安装」，粘贴下面的地址并点击「安装」。

   ```text
   https://raw.githubusercontent.com/iruriQ/BOSS-Greet/main/boss-auto-apply.user.js
   ```

4. **打开 BOSS 网页。** 在同一浏览器登录 [BOSS 直聘职位页](https://www.zhipin.com/web/geek/job)，先搜索自己想投的岗位，然后刷新页面。看到左下角「BOSS Greet」面板，说明已安装成功。
5. **先预览，再投递。** 设置筛选条件和「本轮最多投递数量」；默认固定话术模式下填写一段招呼、检查并勾选确认，点击「筛选合适岗位并预览话术」。确认无误后，取消「试运行：只预览招呼语，不发送」，再点「开始投递」。AI 定制模式另需填写本人经历、接口地址、模型和密钥。

**遇到这几种情况：**

- **下载或扩展商店打不开：** 先检查对应网站是否能访问；已有 `.user.js` 文件可在篡改猴「管理面板 → 实用工具 → 导入」中选择文件安装。离线导入脚本的前提是已安装篡改猴。
- **没有助手面板：** 确认篡改猴及「BOSS 岗位定制招呼助手」都已启用、允许在 BOSS 网站运行，然后回到职位列表刷新。手机 App、聊天页和简历页不是助手的入口。
- **已经装好，还需要一直访问 GitHub 吗：** 不需要。固定话术与筛选只需正常访问招聘网站；GitHub 不可用时不能检查或下载更新，但可继续使用已安装版本。

投递时保持该网页打开，只启用一份投递助手，避免多个版本同时工作。开发命令另见 [开发与发布](development.md)，普通用户不需要执行。

## 第一次使用

先在招聘网站中搜索和筛选目标岗位，再打开左下角面板。通用版首次安装默认选择「固定话术」，修改会自动保存。

| 模式 | 需要填写什么 | 是否需要 API |
| --- | --- | --- |
| 固定话术（默认） | 一段完整的常用打招呼用语，检查后勾选确认 | 不需要 |
| AI 定制（可选） | 本人真实经历、AI 接口地址、模型和密钥 | 需要 |

### 固定话术：无需 API

1. 在「话术模式」选择「固定话术（无需 API）」。
2. 在「固定打招呼内容」中手动填写或粘贴文字，最多 500 字。每个岗位发送相同正文，不自动替换职位、公司或姓名，不自动追加问候、年限或其他内容。不读取 BOSS 后台招呼；升级后保留原有固定文字。
3. 点击「筛选合适岗位并预览话术」检查完整正文；预览不会开聊或发送。
4. 自行检查错别字、语序、用词和事实后，勾选「我已检查并确认以上固定用语，可按原文发送」，再点击「开始」。

修改固定文字会撤销确认，需要重新勾选。未填写或未确认时不能实际发送；固定话术不经过 AI 校对，也不会向模型服务发送数据，即便以前保存过 AI 配置或密钥。资料和 AI 配置只在选择「AI 定制」时显示。

### 本轮投递数量

在「投递设置 → 本轮最多投递数量」填写 1—150 的整数，默认 20 个。达到数量即自动停止，不继续翻页；用户可自行保留其余沟通机会用于手动投递。下一次手动点击「开始投递」会开启新一轮，但仍受本机每日上限和平台实际限制约束。

跳过的岗位不占本轮数量。BOSS 已确认建立沟通的岗位会占用本轮名额，即使后续话术未发送成功；同一岗位不会重复计数。试运行按预览数量停止，不建立沟通或消耗实际投递名额。翻页或临时故障恢复会保留本轮已用数量和原上限，不重新获得整轮数量；达到设定数量后不会自动重启。

### 岗位关键词与公司规模

包含、排除关键词使用独立小输入框，每框填写一个词，点击「添加关键词」增加，点击叉号删除，不需要分隔符。旧版逗号、换行、分号或顿号文本会自动迁移为独立条目。同组按「或」匹配。

**包含优先**：填写包含词时，命中任意包含词即通过关键词检查，即使同时命中排除词；未命中包含词则跳过。因此填写包含词后，排除词不会额外拦截。只有包含词为空时，排除词才独立生效。关键词仍检查原有岗位综合文字范围；不会绕过在线、活跃度、距离、规模等其他条件。启用关键词筛选但无法读取完整 BOSS 岗位描述时跳过，避免用列表摘要漏判。

BOSS 公司规模可多选，只投选中的规模；默认「不限规模」。启用后规模未知的岗位会跳过，不自动放宽范围或补投其他规模。

发布时间优先在内部处理，不新增设置：页面提供明确的「最新发布」排序入口时使用平台排序；否则仅对已加载、能确认发布时间的岗位按新到旧排列，未知时间保持相对顺序。没有可靠时间数据时，在投递进度中提示并沿用平台顺序。**不能保证无时间数据的推荐列表或不同分页之间的全局发布时间顺序**；不把刷新时间、HR 活跃时间或岗位编号当作发布时间。原有招聘方活跃度筛选继续生效。

### 移动和调整窗口

按住顶部标题栏拖动窗口，拖动四边或四角改变宽度和高度。窗口变窄时自动改为单列；标题、导航和底部操作栏固定，中间内容滚动。窗口位置和大小保存到本机，刷新后恢复；右上角「恢复默认位置和大小」可复原。为保证操作按钮可见，最小为 320 × 360 像素；屏幕更小时以屏幕可用范围为限。

预览会先逐个检查岗位，跳过不符合当前关键词、公司规模、距离、在线标记、活跃度及已投递记录等条件的岗位，再为第一个符合条件的岗位准备固定或 AI 话术。当前已加载列表没有匹配项时会尝试加载更多；每次最多检查 200 个岗位、10 批列表，可随时点击「停止」。未找到时说明原因，不放宽条件，也不调用 AI 为不匹配岗位生成话术。预览不写入投递历史、不占本轮数量；修改筛选条件后需重新预览。

### AI 定制：按需开启

在「话术模式」选择「AI 定制（可选，需配置 API）」，再填写以下内容。

| 设置 | 怎么填写 |
| --- | --- |
| 我的简介 | 用一句话介绍自己，可以留空 |
| 工作年限 | 填写真实年限；填写后每条话术都保留，可以留空 |
| 简历资料来源 | 选择「上传或粘贴简历文本」或「读取 BOSS 在线简历」 |
| 真实经历 | 导入后核对并确认，也可展开「当前用于生成话术的经历」手动编辑；每行一项完整句子 |
| 开场问候 | 自由填写；留空默认使用“您好” |
| 每条补充 AI 提效亮点 | 可选；只补充本人经历中实际填写的 AI 实践，不编造 |
| AI 接口地址、模型 | 填写兼容 Chat Completions 的完整接口地址及模型名称 |
| 设置 AI 密钥 | 点击按钮，在弹窗中输入自己的密钥；默认刷新后需重填 |
| 在本机保存 AI 密钥 | 可选，默认关闭；仅保存到篡改猴专用存储，刷新后可恢复；关闭即清除保存 |

填写经历可以采用「使用什么工具，完成什么工作，取得什么结果」的句式。工具不限制求职方向，只使用本人填写的事实。

简历导入提供两个入口：

- **上传或粘贴简历文本**：上传 UTF-8 的 `.txt` / `.md` 文件（最大 256 KB），或直接粘贴正文（最多 30000 字）。PDF / Word 请先复制为文本，再点击「整理为经历草稿」。
- **读取 BOSS 在线简历**：在已登录的 BOSS 直聘网页上，点击「读取我的 BOSS 在线简历」，只读获取本人在线填写的工作、项目、教育、技能等资料；不下载附件 PDF，不修改平台简历。接口失效、登录过期或无可用正文时显示失败，保留当前经历。

两种方式都会先展示可编辑草稿，按原文分行、过滤常见联系方式，不调用 AI，不推算工作年限。核对后点击「确认使用以上经历」，才更新生成话术所用经历；保留上次经历，可点击「恢复上次经历」。简介与年限仍需本人核对填写。完整文本和经历保存在篡改猴的本机存储中；生成话术时，只有当前确认的经历会参与模型请求，不会直接发送上传的完整原始简历。网页演示中的在线读取使用虚构示例，不读取真实账号。

点击「筛选合适岗位并预览话术」查看示例。未配置 AI 服务时，可以根据本地关键词展示标明“未校对”的草稿；实际发送须配置校对服务。点击「开始」后，按「读取招聘要求 → 选经历并生成 → 重大事实核验 → 发送」执行。

AI 模式默认启用「使用 AI 生成岗位定制话术」：一次模型调用完成挑选经历与撰写，生成时就约束事实来源、职责程度、年限和字数；随后单独核验重大事实风险。关闭该选项后，改用本地匹配与模板，**仍须事实核验后才能实际发送定制话术**。

目标字数默认 300，可设置 180—500。设为 300 时，尽量接近 300 字，至少 200 字且不超过 300 字，标点、数字和字母均计数；其他目标的最低字数按目标的三分之二向上取整。升级保留原先填写的数值，不擅自改动。固定话术仍按用户确认的原文发送，不受这条 AI 规则影响。

话术优先介绍有依据的曾任岗位、相关工作年限、真实亮点，以及已有能力能怎样支持岗位工作；不主动介绍学历、毕业院校，也不写“没有某类经验”等短板铺垫。总工作年限不能改成某岗位的从业年限，实习、协助、模拟等实质限定仍须保留。此表达要求在生成、精简和事实修正时统一执行，不新增风格核验或额外模型调用。固定话术继续按确认原文发送。

生成时先选岗位相关经历；招聘介绍较少或相关内容不足时，可从已确认的在线简历或上传资料中补充真实成果、工具应用、项目交付与可迁移能力。最多引用 6 项原始经历，不使用未确认的导入草稿，不为每个岗位重复读取在线简历。不会把个人亮点说成招聘方未提及的职责，也不能编造或重复事实凑字。

生成、篇幅整理、事实修正与发送前检查使用同一字数范围。过短或过长会先修正一次；生成和核验共用这一次预算，不无限追加调用。仍不满足要求时记录为待检查并继续后续岗位，不开聊或发送，并提示核对、补充已确认的简历资料。原始简历不被修改。

「字数允许时补充经历中的 AI 提效亮点」只使用本人真实提供的 AI 实践，不强制凑内容；生成时的本人经历与成果仍须独立事实核验。

### 两种模式共用的功能

- 岗位筛选、距家筛选、去重、自动翻页和投递不依赖 AI 服务。
- 勾选「试运行：只预览招呼语，不发送」后，点击「开始投递」只筛选岗位并预览招呼语，不开聊或发送；取消勾选后才实际投递。
- 「临时故障自动恢复」可选；通用版默认关闭，个人副本默认开启。列表加载或模型连接故障按 30/60/120 秒等待后最多恢复 3 次。
- 关闭「由助手发送打招呼用语」后，沿用 BOSS 自身的默认招呼设置，不要求 API。
- 模式切换会保留各自的正文、个人经历和 AI 配置；等待恢复时切换模式会取消旧续跑，请检查设置后手动开始。

**已有用户更新时保留原模式和已保存的设置**，包括既有个人副本的 AI 定制模式、距离、密钥保存偏好和投递记录；不会因通用版的新默认值改成固定话术。

## 距家筛选

默认关闭，初始距离上限为 10 公里，可调整为 0.1—200 公里。

1. 在岗位列表先打开一个岗位，点击面板的「设置/修改家庭位置」。
2. 在 BOSS 原生路线规划左侧搜索家庭附近地标，点击候选结果。
3. 点击「同步当前起点为家庭位置」，返回岗位列表，刷新家庭位置并开启距离筛选。

网页不能直接读取 App 保存的家庭地址，需要首次手动选择相同起点。同步后在本机保存。筛选使用直线距离，包含上限边界；不是通勤时间或路线里程。工作地址坐标无法确认时跳过该岗位。家庭位置不会发送给 AI 服务。

## 校对、发送和停止

- 固定话术按用户确认的原文发送，不进行 AI 校对。以下校对和模型故障处理说明适用于 AI 定制模式。
- 核验仅拦截明确的重大事实错误：编造经历或技能、实质夸大职责、改变年限与成果数字、声称岗位包含 JD 未提及的职责。正常精简、同义改写、用词与相关性优化建议不拦截，也不额外改写重审。
- 重大错误在同一岗位最多修正一次并复核；生成时的本地内容纠正也共用这一次预算。仍未通过则记录为待检查并继续后续岗位，不开聊、不发送、不停止整轮。格式异常最多重试两次，仍异常同样记为待检查。待检查记录最多保留最近 200 项，可在日志查看原因；后续手动重跑可重新处理。固定话术不受此流程影响。
- 开启自动恢复后，模型连接失败、超时、HTTP 408/429/5xx，以及 BOSS 列表加载超时，会按 30/60/120 秒等待后最多自动恢复 3 次，保留计数与已处理岗位；不会重试已经开聊或发送的操作。模型持续异常超过上限后保留暂停。
- AI 定制模式密钥丢失时先等待输入，不反复发出无鉴权请求；模型 HTTP 401 时暂停并清除失效密钥，更新密钥后自动继续原进度。选择本机保存后，刷新时可加载与同一接口地址绑定的密钥；未保存则需要补填。自动恢复仅接续此前正在运行的任务，不会在新打开页面时主动开始投递。
- BOSS 提示“今天已与若干位 BOSS 沟通，还剩若干次沟通机会”且剩余次数大于 0 时，仅确认平台返回的当前岗位同源继续按钮一次，再在对应聊天页核对招聘者、岗位及可读取的会话记录后发送；不重复确认或盲目重试。剩余次数为 0、核验失败或其他未知提醒仍暂停。
- 验证码、登录异常、平台限制、会话身份不符或发送结果不明时保持暂停。每日上限、单次上限、列表处理完成或手动停止都不会触发自动重启；等待恢复时点击「停止」也会取消续跑。
- 聊天输入框或发送按钮未就绪时，最多等待 10 秒，并连续两次确认输入内容、会话和按钮状态；输入被前端清空时最多重填 3 次，只填写空框，不覆盖其他草稿。仍未就绪且确认未点击发送时，记录为 `not-sent` 并跳过该岗位继续；保留已建立沟通的计数与招聘者去重记录。点击发送后发生的异常仍属于未确认发送，不自动重发；日志显示具体未就绪原因。
- 只有确认最终消息已投递才计为成功。即时回执缺失时，可只读核对同一会话的服务器历史；不重复点击发送。
- 「核查未确认发送（只读）」用于检查已有记录，不会重新发送。旧记录缺少完整待核查文本时，不自动改成成功或清除。
- 「检查/加载更多（不投递）」只测试下一批岗位加载。只有平台明确表示无更多且状态稳定时，才报告列表结束；加载超时会说明原因。
- 默认自动翻页，跳过已处理记录和猎头，只处理两周内活跃的 BOSS。本机每日上限 150 次，平台可能有更低限额。
- BOSS 只在岗位之间随机等待 1—3 秒，筛选、去重或待检查的岗位同样只计一次；取消读取、开聊和打开聊天页前的逐步骤等待，也不叠加原有 4—10 秒投递等待。AI 话术核验通过且聊天框就绪后，发送前单独随机等待 1—3 秒；固定话术和 BOSS 平台默认招呼不加发送前等待。岗位间隔只抽一次，刷新保留剩余时间；翻页原有的 3 秒等待及实际页面加载、身份核对、发送回执等待保留。等待期间可停止，平台异常仍暂停，不保证避免平台限制。其他平台保留原有间隔。
- 随机间隔并非 BOSS 公布的安全阈值，缩短间隔也可能提高请求频率，不能保证避免平台限制。检测到异常登录、环境异常或验证时停止并清除自动续跑；提示消失也不会自动恢复，需用户在网页处理后手动点击开始或预览。

由助手发送 AI 或固定话术时，开聊前会读取 BOSS 自动招呼开关；若已开启，则关闭并重新确认，关闭失败不继续开聊或发送。仅修改开关，保留平台招呼正文和模板。仅预览或关闭助手发送时不更改平台设置；如需恢复平台自动招呼，请在 BOSS 中重新启用。发送前若发现会话已有本人文字消息，会阻止补发并暂停核查。

猎聘沿用原有沟通流程，必要时发送用户配置的「猎聘招呼语」；智联招聘、前程无忧和实习僧沿用 fork 的申请流程。实习僧保留在线/附件简历、到岗时间、实习时长与每周出勤设置，并为一轮投递复用投递窗口。BOSS 的定制话术和距家筛选仅用于 BOSS。

## 资料保存在哪里

- 简介、经历、偏好、家庭起点及投递记录保存在用户浏览器的脚本存储中；不自动写回本仓库。
- API Key 默认只保留在当前页面内存。明确勾选「在本机保存 AI 密钥」后，仅写入篡改猴专用存储，不使用网页 localStorage；保存内容绑定完整模型接口地址，更换接口会清除旧密钥。关闭保存会清除已保存密钥。篡改猴备份可能包含此项，请自行保管备份。密钥始终不写入配置、日志或构建文件。
- 仅 AI 定制模式会将 JD、候选经历与待校对话术发送到用户自己配置的模型服务。固定话术模式不调用模型。AI 选择经历时会发送参与选择的经历；校对时发送已选中的经历。模型校对可能遗漏语言问题。
- 模型服务默认要求 HTTPS，本机服务允许 HTTP。脚本声明 `@connect *`，供用户自行指定模型服务，实际目标取自用户配置。
- 如需提交 Issue，请只附脱敏截图和复现步骤，不附简历、地址、密钥或私人构建文件。

## 版本更新提醒

助手启动后自动检查 GitHub `main` 分支上的 `releases.json`，每 12 小时最多检查一次（不上传简历或密钥）。发现更高的正式版本号时，会显示版本号和主要更新内容。投递、预览或导入运行中会推迟弹窗，不打断操作。

- 「更新到新版」打开篡改猴安装页，确认更新后刷新招聘页面；只打开页面不会被记为更新成功。
- 「继续使用当前版本」关闭弹窗，同一个新版不再自动提醒；下一版仍会提醒，也可随时点底部「检查更新」。
- 实际加载更高版本后，显示「已更新至…」和跨过的各版更新说明，点击知道后不再重复展示。首次安装只记录当前版本。
- 更新沿用脚本名称、namespace 和存储键，保留现有设置与记录；个人副本不直接安装通用版。GitHub 无法访问时可继续使用当前版本。

旧代码没有更新检查功能，需要先手动安装一次含该功能的版本；此后才能接收提醒。脚本通过 `@downloadURL none` 关闭篡改猴的原生自动检查，使用弹窗让用户选择；不在后台替用户安装。若用户自行覆盖脚本管理器的更新设置，则以其设置为准。

## 兼容范围与旧版用户

本版与上游脚本、私人构建使用不同名称和存储空间，分别保存配置和记录。旧版用户原有记录不会自动迁入通用版；继续使用已有记录时应更新对应的私人构建。不同版本的去重记录不共用，投递时只运行所需的一份。
